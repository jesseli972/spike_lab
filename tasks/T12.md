# T12: Readout and preset menu

Read `CLAUDE.md` before starting.

**Goal:** show the result in numbers, and let the user pick a preset.

**Files:** `src/ui/readout.js`, `src/ui/panel.js`. **Needs:** T11.

1. Readout: a small box fixed to the top-left of the page, styled inline. `show(result)` displays the outcome as a large word (IN in green; OUT, NET, or ANTENNA in red), the landing x and z in meters, flight time in seconds, peak height in meters, and net clearance in centimeters. Show a dash for any value that is `null`. `clear()` empties it.
2. Panel: add a Preset dropdown at the top that lists the names in `PRESETS`. Choosing one calls `setLaunch(preset.launch)`.

**Done when:**

- After a launch, all five values appear with units.
- Choosing each preset moves the sliders to its values.
- Launching each preset works without errors.

**Watch out:** do not edit `src/ui/presets.js`; T13 owns it.
