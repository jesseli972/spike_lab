# T09: Control panel

Read `CLAUDE.md` before starting.

**Goal:** the sliders and buttons, producing a Launch object.

**Files:** `src/ui/panel.js`. **Needs:** T01.

1. Build a `lil-gui` panel with these controls, in this order:

| Control | Range | Default |
| --- | --- | --- |
| Contact x (m) | −12 to −0.5 | −9.5 |
| Contact z (m) | −4.5 to 4.5 | 0 |
| Contact height (m) | 0.5 to 3.8 | 2.6 |
| Speed (km/h) | 20 to 130 | 65 |
| Aim left/right (°) | −30 to 30 | 0 |
| Vertical angle (°) | −30 to 45 | 12 |
| Spin type | none, top, back | none |
| Spin (rpm) | 0 to 600 | 0 |
| Net height | Men 2.43, Women 2.24 | Men |
| View | `viewNames` | broadcast |

2. Add a Launch button. Pressing Space also launches.
3. `getLaunch()` returns a Launch object. Convert km/h to m/s by dividing by 3.6.
4. `setLaunch(launch)` sets every control from a Launch object and refreshes the display.
5. Call `onLaunch(getLaunch())`, `onViewChange(name)`, and `onNetHeightChange(height)` when the user acts.

**Done when:**

- Pressing Launch logs a Launch object whose speed is in m/s.
- `setLaunch(getLaunch())` changes nothing on screen.
- Changing View or Net height calls its callback once per change.
- Space launches, but not while the user is typing in a field.
