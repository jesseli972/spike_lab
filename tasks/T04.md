# T04: Lights and shadows

Read `CLAUDE.md` before starting.

**Goal:** gym-style lighting with a clean ball shadow on the floor.

**Files:** `src/scene/lights.js`. **Needs:** T01.

1. Add a `HemisphereLight` at intensity about 0.6 for soft fill.
2. Add a `DirectionalLight` at position (−6, 14, 8) aimed at the origin, with `castShadow` on.
3. Shadow settings: map size 2048; orthographic shadow camera with left/right ±11, top/bottom ±7, near 1, far 40; bias −0.0005; normalBias 0.02.
4. Set `renderer.shadowMap.type` to `THREE.PCFSoftShadowMap`. Set a plain scene background color.

**Done when:**

- A temporary sphere at (4, 2, 0) casts a clear shadow on the floor.
- The same sphere casts a shadow at all four court corners.
- The floor has no striped shadow artifacts, and the shadow is not detached from the sphere when it rests on the floor.
- The temporary sphere is removed before you report.
