# T01: Scaffold and contracts

Read `CLAUDE.md` before starting.

**Goal:** a running, deployed, empty app in which every module from the contracts already exists as a stub. This is what lets eight agents work at once.

**Files:** the whole repo skeleton. **Needs:** nothing. **Who:** you or your strongest agent.

1. Create the project with Vite's vanilla template (`npm create vite@latest spike-lab -- --template vanilla`), or scaffold it in the current folder if `CLAUDE.md` and `tasks/` are already here. Keep `CLAUDE.md` and `tasks/` at the repo root. Install `three` and `lil-gui`. Install `vitest` as a dev dependency.
2. Create `src/constants.js` with every constant from `CLAUDE.md`.
3. Create every file named in the module contracts as a stub. Each stub exports the exact function names and returns a harmless placeholder: an empty `THREE.Group`, an object whose methods do nothing, or an empty Result.
4. In `src/ui/presets.js`, export `PRESETS` with the three starting presets listed in `tasks/T13.md`. Store speed in m/s (km/h divided by 3.6).
5. Write `src/main.js`: a `WebGLRenderer` (antialias on, shadow map on, pixel ratio capped at 2), a scene, a `PerspectiveCamera` (fov 50, near 0.1, far 200), `OrbitControls`, a resize handler, and an animation loop that computes `dt` from a clock. Call every stub so later work appears without editing this file. Add a temporary `GridHelper`.
6. Add scripts `dev`, `build`, and `test`. Set `base: './'` in `vite.config.js`. Add a GitHub Actions workflow that builds and deploys `dist` to GitHub Pages.
7. Add one trivial passing test in `tests/`.

**Done when:**

- `npm run dev` shows a grid you can orbit with the mouse.
- `npm test` and `npm run build` both pass.
- The GitHub Pages link loads the same scene.
- Every contract function can be imported without an error.
