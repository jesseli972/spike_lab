# T06: Collision checks

Read `CLAUDE.md` before starting.

**Goal:** three pure functions that decide net contact, floor contact, and in or out.

**Files:** `src/physics/collide.js`, `tests/collide.test.js`. **Needs:** T01.

1. `checkNetCrossing(prev, curr, netHeight)` is called only when `prev.x < 0` and `curr.x >= 0`. Find the crossing point by linear interpolation at x = 0. Then test in this order and return the first match:
   - `'antenna'`: the point's |z| is within `BALL_RADIUS + 0.01` of 4.5, and its y is between `netHeight − NET_BAND` and `netHeight + ANTENNA_ABOVE_NET`.
   - `'outside'`: |z| > 4.5.
   - `'net'`: y < `netHeight + BALL_RADIUS`. This also covers a ball that goes under the net.
   - `'clear'`: anything else, with `clearance = y − BALL_RADIUS − netHeight`.
2. `clearance` is `null` unless the type is `'clear'`.
3. `checkFloor(prev, curr)`: return `null` if `curr.y > BALL_RADIUS`. Otherwise interpolate to the point where y equals `BALL_RADIUS` and return it.
4. `isInCourt(point)`: true when |x| ≤ 9 + `LINE_TOUCH_TOL` and |z| ≤ 4.5 + `LINE_TOUCH_TOL`. Use the court constants, not the literal 9 and 4.5.

**Done when** tests cover and pass:

- One case for each of the four net results, plus a ball that passes under the net.
- A ball exactly `BALL_RADIUS` above the tape counts as `'clear'` with clearance 0.
- A floor hit halfway between two samples returns the midpoint.
- A point on the line is in; a point 0.1 m past the line is out.

**Watch out:** do not import three. A ball that touches the net ends the flight in this project, even though a real serve may roll over.
