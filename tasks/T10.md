# T10: simulate()

Read `CLAUDE.md` before starting.

**Goal:** one function that turns a Launch into a complete flight. The whole path is computed at launch, then played back, so results are identical on every computer.

**Files:** `src/physics/simulate.js`, `tests/simulate.test.js`. **Needs:** T05, T06.

1. Start from `launchToState(launch)`. Record the first sample at t = 0. Keep three flags: `crossed = false`, `outside = false`, `netClearance = null`.
2. Loop while t < `MAX_FLIGHT_TIME`. Each pass, compute `next = rk4Step(state, omega, PHYSICS_DT, DRAG_COEFF)`, then:
   - If `state.pos.x < 0` and `next.pos.x >= 0`, call `checkNetCrossing`. On `'net'` or `'antenna'`: add a final sample at the returned point, set that outcome, set `landing` to `null`, and stop. On `'outside'`: set `outside = true`. On `'clear'`: store the clearance. In the last two cases set `crossed = true`.
   - Call `checkFloor`. If it returns a point: add a final sample there, set `landing` to its x and z, and stop. The outcome is `'in'` only if `crossed` is true, `outside` is false, `landing.x > 0`, and `isInCourt` is true. Otherwise it is `'out'`.
   - Otherwise record the sample, advance t by `PHYSICS_DT`, and continue.
3. If the loop times out, the outcome is `'out'` and `landing` is `null`.
4. Fill in `flightTime` (the last sample's t), `peakHeight` (the largest y seen), `netClearance`, and `omega`.

**Done when** these tests pass (speeds in m/s, net height 2.43, no spin unless stated):

| Launch | Expected outcome |
| --- | --- |
| pos (−1.5, 3.2, 0), speed 22, azimuth 0, elevation −17 | `'in'` |
| pos (−2, 2.0, 0), speed 20, azimuth 0, elevation 0 | `'net'` |
| pos (−9.5, 2.6, 0), speed 30, azimuth 0, elevation 10 | `'out'` (long) |
| pos (−1.5, 3.2, 0), speed 22, azimuth 45, elevation −17 | `'out'` (wide) |
| pos (−1.5, 3.2, 4.0), speed 22, azimuth 45, elevation −17 | `'out'` (crossed outside the antenna) |

- The same Launch run twice gives deeply equal Results.
- When a flight ends on the floor, the last sample's y equals `BALL_RADIUS`.
- `netClearance` is a number for the first row and `null` for the second.

**Watch out:** do not import three. If a test row fails, report it; do not change the expected outcome or any constant.
