# T05: Forces, integrator, launch

Read `CLAUDE.md` before starting.

**Goal:** the math that moves the ball, as pure functions with tests.

**Files:** `src/physics/launch.js`, `src/physics/forces.js`, `src/physics/integrator.js`, `tests/physics.test.js`. **Needs:** T01.

1. `launchToState(launch)`: build `pos`, `vel`, and `omega` exactly as the Launch angles section of `CLAUDE.md` says.
2. `liftCoeff(S)`: return `S / (2.32 * S + 0.4)`, or 0 when S ≤ 0.
3. `acceleration(vel, omega, dragCoeff)`: let `k = 0.5 * AIR_DENSITY * PI * BALL_RADIUS² / BALL_MASS` and `speed = |vel|`. Sum three parts:
   - gravity: (0, −GRAVITY, 0)
   - drag: `−k * dragCoeff * speed * vel`
   - lift: only if `|omega| > 0` and `speed > 1e-6`. Let `S = BALL_RADIUS * |omega| / speed` and `dir = normalize(cross(omega, vel))`. Lift is `k * liftCoeff(S) * speed² * dir`. If the cross product has near-zero length, lift is zero.
4. `rk4Step(state, omega, dt, dragCoeff)`: classic fourth-order Runge-Kutta on position and velocity. Return a new state. Never change the inputs.
5. Write the tests listed under "Done when".

**Done when** these tests pass:

- Azimuth 0, elevation 0, speed 20 gives velocity (20, 0, 0). Topspin omega points along −z; backspin along +z.
- With `dragCoeff` 0 and no spin, 240 steps from position (0, 2, 0) and velocity (10, 5, 0) end at x = 10 and y = 2.095, within 1e-6.
- With `dragCoeff` 0.2, the same launch ends at x < 10.
- For velocity (20, 0, 0), the y acceleration is below −9.81 with topspin and above −9.81 with backspin.
- Input objects are unchanged after every call.

**Watch out:** `cross(a, b) = (a.y*b.z − a.z*b.y, a.z*b.x − a.x*b.z, a.x*b.y − a.y*b.x)`. Do not import three. Do not tune the lift formula.
