# T08: Camera rig

Read `CLAUDE.md` before starting.

**Goal:** five camera views with smooth switching.

**Files:** `src/cameras/rig.js`. **Needs:** T01.

1. `names` is `['broadcast', 'side', 'server', 'follow', 'free']`.
2. Fixed views, as position and look-at target:
   - broadcast: (−17, 8, 0) looking at (2, 1, 0)
   - side: (0, 4, 15) looking at (0, 1.5, 0)
   - server: the server position plus (−1.5, 0.3, 0), looking at (6, 1, server z). `setServerPos(pos)` updates it.
3. `setView(name)`: move from the current position and target to the new ones over 0.5 seconds with smoothstep easing.
4. follow: each frame the wanted position is the ball position, minus 4 m along the ball's horizontal direction of travel, plus 1.5 m up. Move toward it with `camera.position.lerp(wanted, 1 − exp(−6 * dt))` and look at the ball. If `ballPos` is `null`, behave like broadcast.
5. free: turn `controls.enabled` on. In every other view turn it off.
6. Never let the camera go below y = 0.5.

**Done when:**

- A temporary key handler (keys 1 to 5) switches views and each transition is smooth.
- The mouse orbits only in the free view.
- The follow view tracks a temporary moving point without jitter.
- The temporary code is removed before you report.
